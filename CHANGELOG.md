# Changelog

## [1.2](https://github.com/vysakhrnambiar/Remindo/releases/tag/v1.2) · November 16, 2026

- Schedule a task for a single date, or choose which weekdays a daily task should run.
- Set nudge times and feedback times separately. A weekly task can send hourly nudges on Monday and ask how it went on Sunday evening. Turn nudges off to get just the check-in.
- Answer any check-in with **Yes**, **No**, **Partial**, **Not Applicable**, or **Others**. Comments are optional.
- Tap **Awaiting feedback** on the home screen to see pending check-ins, oldest first. Each shows how long it has been waiting. Older items and larger backlogs can trigger one grouped follow-up per day.
- Open **History → Day** for a daily recap with completed tasks first. Week, month, and custom ranges show day counts for each task and outcome. Tap a count to read the dated comments. Missed, not applicable, and awaiting feedback are counted separately.

**Updating from 1.1:** Open the signed 1.2 APK and tap **Update** to keep existing schedules, feedback, and comments.
